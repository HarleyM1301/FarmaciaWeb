# Sitio de demostración Farmacia Vital

Sitio estático, adaptable a móvil y en español. La navegación superior enlaza a las secciones Inicio, Servicios, Nosotros y Contacto.

## Publicación con GitHub Pages

En el repositorio `HarleyM1301/FarmaciaWeb`, abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama **main** y la carpeta **/docs**, y guarda. GitHub publicará el sitio en:

https://harleym1301.github.io/FarmaciaWeb/

Los cambios futuros dentro de `docs/` se publicarán al actualizar la rama `main`.
